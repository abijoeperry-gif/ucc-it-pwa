## Project Overview
This Progressive Web Application (PWA) serves the Department of Information Technology at the University Commonwealth Caribbean (UCC). It provides an installable, mobile-responsive portal containing:
- Faculty & Staff Directory with direct click-to-call and mailto actions.
- Department Course Offerings loaded with credit counts and prerequisites.
- Structured Admissions pathways and entrance scholarship criteria.
- Official UCC Social Media channels.
- Global email floating action button (FAB) for the Head of Department.

## Tech Stack
- Laravel 11 / PHP 8.2+
- Bootstrap 5 & Bootstrap Icons
- Service Worker & Web App Manifest (PWA)
